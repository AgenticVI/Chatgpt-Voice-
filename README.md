# AI Voice Learning Assistant — Mobile Prototype

A mobile-first prototype demonstrating an end-to-end user journey for an AI-powered conversational voice learning app:

1. **Context & Topic Detection**: Clean mobile chatbot interface with intent discovery chips and prompt suggestions.
2. **AI Response & Proactive Voice Nudge**: Structured AI responses with a glowing **Voice Nudge CTA** card (*"Want to practice this out loud?"*).
3. **One-Tap Seamless Transition**: Instant transition without modal friction into voice mode.
4. **Voice Mode & Context Handoff**: Dedicated voice screen featuring a procedural/3D **Luminous Sky Orb** canvas visualizer, context pill, and audio waveforms.
5. **Interactive Practice Session**: Pronunciation drill with Web Speech synthesis (`AI Speaking`) and live speech recognition / clarity scoring (`Your Turn`).
